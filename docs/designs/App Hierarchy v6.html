v6 · LOCKED

v6 commits to the direction from v5 review: kill the wizard, give Add Account both an up-front choice and a fallback, use the Plaid native picker (we don't build our own), keep auto-categorize silent with a banner, fold manual import into Add Account, and put net worth + allocation + spending + budgets + goals on one Insights page. AI provider lives in Settings; AI chat is deferred.

00

What went off the chart

Quick honest read of where the hi-fi journey diverged from the requirements, so v5 doesn't repeat it.

✗ Hi-fi went off the chart

  • Forced wizard shoved 3 unrelated functions into 1 linear flow. linear
  • Onboarding "Connect bank" duplicated the in-app Accounts → Connect bank action. Two homes for the same job.
  • Onboarding "Import progress" page existed only to fill a step — auto-import is a background outcome, not a screen.
  • "Manual import" route in the sidebar AND a "+ add manually" tile in the wizard — same function, two doors.
  • AI advisor mentioned in onboarding ("AI you can audit"). User said: AI provider is global setup, don't emphasize.
  • Vault passphrase + recovery key + restore-from-backup at sign-up — way past the requirement of "sign up".

✓ v5 principles

  • 5 requirements → 5 surfaces. Sign up · Add account · Transactions · Insights · Net worth. No wrapper.
  • One door per job. Adding an account — Plaid or manual — is always the same screen, regardless of how you got there.
  • Auto-categorize is silent. It runs on import; users review by exception on the Transactions page.
  • Manual import lives inside Add Account — it's just the second of two paths. Not a separate sidebar route.
  • Review surface is one page. Net worth + asset allocation + spending categories + trend collapse into a single Insights view.
  • No AI mentions in onboarding. The AI provider is set during instance setup once; users never see it again unless they open Settings.
